# Nelko P21 for Linux Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A polished Tauri desktop app and an MCP server for Linux that print template-based labels to a Nelko P21 over Bluetooth Classic and detect the loaded roll automatically.

**Architecture:** One Cargo workspace. `nelko-core` holds everything real: protocol, transport, lock, config, rendering, templates, and a `Nelko` service facade. `nelko-mcp` (stdio MCP) and the Tauri app (`app/src-tauri`) are thin shells over the `Nelko` facade, so both print byte-identical jobs.

**Tech Stack:** Rust 1.99 (edition 2024), tokio, bluer (BlueZ, RFCOMM), tiny-skia, cosmic-text, resvg, qrcode, barcoders, image, serde/serde_json/toml, dirs, fs4, thiserror, rmcp (stdio), Tauri v2, Svelte 5 + TypeScript + Vite.

**Spec:** `docs/superpowers/specs/2026-11-12-nelko-p21-design.md`. Read §3 (protocol) and §3.4 (APK facts) before Tasks 2–3.

## Global Constraints

- Linux only (KDE Plasma 6 / Wayland, BlueZ). No root, no manual `rfcomm bind`.
- Bluetooth Classic RFCOMM **channel 1**. Only one connection at a time: connect per job, then **disconnect right away**.
- Every connection takes the cross-process lock `$XDG_RUNTIME_DIR/nelko-p21.lock` first (wait up to 10 s, then `PrinterError::Busy`).
- 203 DPI = 8 dots/mm. The head is 96 dots wide. Bitmap bit 0 = black, MSB first.
- Printable length: 40 mm → 35.5 mm (offset 2.25 mm), 30 mm → 25 mm (offset 2.5 mm), otherwise length − 2 mm (offset 1 mm).
- Default gap is 5 mm when the tag doesn't give one. Continuous paper → `GAP 0 mm,0 mm`.
- Density 1–15, default 15. MCP copies are capped at 10. `INITIALPRINTER` is never sent anywhere.
- Don't copy code from the AGPL repos or from the decompiled APK. Implement from the spec's facts.
- Don't commit `nelko.apk` or anything from `~/nelko-re`.
- Bundled assets: Lucide icons (ISC), OFL fonts only (Inter Regular and Bold, plus one condensed and one rounded OFL face of the builder's choice). Each license file is placed next to its asset.
- All label pixels come from Rust; the frontend only shows PNGs. Preview and print use the same `RenderedLabel`.
- Config is `~/.config/nelko/config.toml`; user templates are `~/.config/nelko/templates/*.json`.

## Review Focus

1. **Printer off, out of range, or held by a phone.** Connect fails within about 10 s with a plain message ("Printer is off, out of range, or connected to another device"), with no hang. Owned by Task 3: `connect_failure_maps_to_unreachable`.
2. **Text too long for the label.** Auto-fit shrinks to a 6 px minimum, then truncates with "…", with no panic and no silent clipping. Owned by Task 5: `autofit_truncates_with_ellipsis`.
3. **Invalid barcode/QR data or empty fields.** An empty field renders as nothing (or the template default in the gallery thumbnail). Data that isn't valid EAN-13 falls back to Code128. Non-ASCII data for Code128 gives `RenderError::InvalidData` with a message, not a panic. Owned by Task 6: `barcode_invalid_data_errors`, `ean_falls_back_to_code128`.
4. **App and MCP printing at the same moment.** The second waits; after 10 s it gets "Printer busy". Owned by Task 3: `lock_second_acquire_times_out`.
5. **Unicode, emoji, or glyphs a font lacks.** cosmic-text font fallback is used, with no panic and no tofu-only output. Owned by Task 5: `renders_unicode_without_panic`.

### Task 3: Transport, lock, printer session, config

**Files:**
- Create: `crates/core/src/transport.rs`, `crates/core/src/lock.rs`, `crates/core/src/printer.rs`, `crates/core/src/config.rs`

**Interfaces:**
- Consumes: Task 2 `protocol::*`, `geometry::LabelSize`.
- Produces:
  - `#[async_trait] pub trait Transport: Send { async fn write_all(&mut self, b: &[u8]) -> Result<(), PrinterError>; async fn read_reply(&mut self, idle: Duration, max: Duration) -> Result<Vec<u8>, PrinterError>; }`
    - `read_reply` collects bytes until no byte arrives for `idle` (default 150 ms), or `max` (default 2 s) passes. It errors with `Timeout` if nothing arrives at all.
  - `pub struct RfcommTransport` with `connect(mac: &str, timeout: Duration /* 10s */) -> Result<Self, PrinterError>`.
    - Uses `bluer::rfcomm::Stream::connect(SocketAddr::new(addr, 1))` wrapped in `tokio::time::timeout`.
    - Any failure or timeout → `PrinterError::Unreachable("Printer is off, out of range, or connected to another device")`.
    - Writes go in 1024-byte chunks.
  - `pub struct MockTransport { pub written: Vec<u8>, pub replies: VecDeque<Vec<u8>> }`, `impl Transport`. Each `read_reply` pops the next reply; an empty queue → `Timeout`.
  - `pub struct PrinterLock` with `acquire(timeout: Duration) -> Result<PrinterLock, PrinterError>` and `acquire_at(path: &Path, timeout)` for tests.
    - Uses an exclusive `fs4` lock, retried every 100 ms; when the time is up → `Busy`. The lock is released on Drop.
  - `pub struct Printer<T: Transport> { t: T }`:
    - `new(t)`
    - `status() -> Result<PrinterStatus>`
    - `roll() -> Result<Option<RollInfo>>`
    - `battery() -> Result<Battery>`
    - `config() -> Result<DeviceConfig>`
    - `print(job: &PrintJob) -> Result<(), PrinterError>`: check status first; anything other than Ready → `Err(Status(s))`. Then write `encode_job`, then poll status every 300 ms until Ready, for up to `5 s + 3 s × copies`.
    - `self_test()`
  - `pub struct Config { pub printer_mac: Option<String>, pub printer_name: Option<String>, pub density: u8 /*15*/, pub rotation: Rotation, pub last_label: Option<LabelSize>, pub manual_label: Option<LabelSize> }`
    - `#[serde(default)]`, plus `Config::load() -> Result<Config>`, `save(&self)`, `load_from(path)`, `save_to(path)`, `fn templates_dir() -> PathBuf`.
    - `Rotation` lives in `render/mod.rs` (Task 5). Define `pub enum Rotation { Cw, Ccw }` here in `config.rs` instead, with default `Cw`, and re-export it from `render`.

### Task 8: Service facade

**Files:**

**Interfaces:**
- Consumes: everything above.
- Produces:

  - `pub struct PrinterReport { pub connected: bool, pub name: Option<String>, pub status: Option<PrinterStatus>, pub battery: Option<Battery>, pub roll: Option<RollInfo>, pub firmware: Option<String>, pub error: Option<String> }` (Serialize)

  - `pub struct Nelko { config: Mutex<Config>, store: RwLock<TemplateStore>, connector: Box<dyn Connector> }`
    - `pub trait Connector: Send + Sync { async fn open(&self, mac: &str) -> Result<Box<dyn Transport>, PrinterError>; }`, with `RfcommConnector` (real) and a test connector that returns a `MockTransport`.
  - Methods (async, `&self`):
    - `Nelko::new()`, which loads the config and store with `RfcommConnector`
    - `with(config, store, connector)` for tests
    - `report() -> PrinterReport`: lock, connect, then status + battery + config + roll, then disconnect. It never returns Err; failures go in `error`. A detected roll updates `config.last_label`.
    - `resolve_size(explicit: Option<LabelSize>, query_printer: bool) -> Result<ResolvedSize, NelkoError>`: the order is roll (if `query_printer`), then explicit, then `last_label`, then `manual_label`, else `Err(UnknownLabelSize)`. The gap comes from the roll if present, else 5; continuous → 0.
    - `templates() -> Vec<Template>`, `template(id) -> Option<Template>`, `save_template(t)`, `delete_template(id)`, `duplicate_template(id, name)`

    - `print(req: PrintRequest) -> Result<ResolvedSize, NelkoError>`: one lock and one connection for the whole operation:
      1. query the roll
      2. resolve the size
      3. render
      4. `to_print_bitmap(config.rotation)`
      5. `Printer::print`
      6. save `last_label`
      7. disconnect
      Density is `req.density`, else the config value, clamped to 1–15.
    - `print_image(path, size: Option<LabelSize>, copies, dither)`: wraps the `image` template.
    - `config() -> Config`, `update_config(f: impl FnOnce(&mut Config))`, which also saves.
